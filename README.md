## 📋 常用指令 (Discord 原生斜線指令)

在 Discord 聊天框中輸入 `/kurisu-` 即可自動跳出完整的自動補全選單與參數提示：

| 斜線指令 (Slash Command) | 說明 | 範例與參數 |
| :--- | :--- | :--- |
| **`/kurisu-help`** | **【指令說明手冊】**，以精美 Embed 卡片展示所有支援的功能 | `/kurisu-help` |
| **`/kurisu-search`** | **【強制觸發聯網搜尋】**，檢索即時資料並以群友人設回覆 | `/kurisu-search query:台北現在天氣` |
| **`/kurisu-profile`** | **【查詢個人畫像】**，查看機器人為你或指定群友建立的特徵記憶 | `/kurisu-profile` 或 `/kurisu-profile user:@群友` |
