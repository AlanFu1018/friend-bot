# 💖 紅莉栖動態好感度與人際進展系統計畫 (Persona Favorability & Progression Plan)

本文檔詳細評估並設計 **Friend-Bot** 讓機器人（牧瀨紅莉栖）對不同使用者建立**獨立好感度（Favorability）**與**人際關係進展（Relationship Progression）**的完整實作方案。

---

## 🎯 一、 核心願景與設計哲學

### 1. 為什麼需要動態好感度？
在群聊環境中，每位群友與紅莉栖的互動深度、互動頻率和聊天主題截然不同：
- 有些群友經常聊科學理論、請喝 Dr Pepper、認真關心她的研究；
- 有些群友喜歡中二胡鬧、開她玩笑、甚至挑釁她的管理權限；
- 有些則是初次加入的新面孔。

如果機器人對所有人採取「千篇一律」的回應態度，會缺乏擬真感與沉浸感。**動態好感度系統** 能讓紅莉栖對不同群友展現出**層次分明、因人而異的傲嬌防線與情緒反饋**。

### 2. 牧瀨紅莉栖的「好感進展 (Progression)」核心特點
紅莉栖作為典型的「天才傲嬌神經科學家」，好感度的提升**絕對不是變成百依百順的客服妹**，而是**「傲嬌防禦層的轉化與信任深度的演進」**：
- **低好感度**：高冷、防備、公事公辦、以科學邏輯駁斥、絕不承認任何私交。
- **中好感度 (預設)**：標準傲嬌、嘴硬心軟、愛吐槽、被調侃時會害羞反駁（`別誤會了！`）。
- **高好感度**：防線頻繁崩潰（破防顏文字增加）、私下主動關心對方、主動分享研究與心事，但表面依舊維持最後一絲嘴硬（嬌 70% / 傲 30%）。

### 3. 核心運作原則：【完全隱密，絕無系統提示】
> [!IMPORTANT]
> **好感度是紅莉栖「內在的情感底色」，絕不破壞對話沉浸感！**
> - ❌ **絕對不在群聊中跳出任何升降級或得分提示**（如：`好感度 +2`、`晉升為實驗室夥伴` 等系統干擾訊息一律不發送）。
> - ✅ **只有在用戶主動執行 `/kurisu-profile` 指令時，才在個人卡片中可視化展示**當前的好感度進展條與關係階段。

## 📊 二、 關係進展階段設計 (Progression Tiers)

系統將好感度數值量化為 **0 ~ 100 分**，並劃分為 4 個階段（Tiers）：

```
 0                    20                   50                   80                 100
 ├────────────────────┼────────────────────┼────────────────────┼───────────────────┤
 │  Tier 1: 陌生警戒  │  Tier 2: 熟識群友  │  Tier 3: 實驗室夥伴│  Tier 4: 靈魂共鳴 │
 │  (Stranger)        │  (Familiar - 預設) │  (Labmem Partner)  │  (Steins;Gate)    │
 └────────────────────┴────────────────────┴────────────────────┴───────────────────┘
```

## 🛠️ 三、 修正後方案 C：隱密混合模式 (Hybrid Stealth Mode)

### 方案 C 核心機制
1. **數值與階級量化 (0~100)**：提供精細的情感沉澱。
2. **每日增加上限可配置 (`daily_gain_limit`)**：
   - 透過 `config/config.yaml` 自由調整每日最多增加點數（預設 5 點），杜絕刷頻洗好感。
3. **完全無系統提示 (Silent Backend Updating)**：
   - 提煉時在後端默默結算分數並更新資料庫。
   - 日常對話中紅莉栖的態度自然轉變，**聊天頻道絕不彈出任何分數跳動提示**。
4. **顯式查詢 (`/kurisu-profile`)**：
   - 僅當用戶主動輸入 `/kurisu-profile` 時，才在卡片中清晰展示數值、進度條與關係稱號。

## ⚙️ 四、 設定檔規劃 (`config/config.yaml`)

在 `config.yaml` 新增好感度設定區塊，所有關鍵閾值均可由管理員自訂：

```yaml
# ==============================================================================
# 好感度與人際進展 (Favorability & Progression) 設定
# ==============================================================================
favorability:
  # 是否啟用動態好感度與人際關係進展系統
  enable_favorability: true

  # 新用戶初始預設好感度數值 (0 ~ 100)
  default_favorability: 30

  # 單一用戶「每日好感度增加上限」（防止洗頻刷分）
  daily_gain_limit: 5

  # 單一用戶「每日好感度扣分上限」（避免因少數誤判過度扣分）
  daily_loss_limit: 10

  # 各 Tier 好感度門檻
  tier_thresholds:
    stranger: 0
    familiar: 20
    trusted: 50
    cherished: 80
```

## 📈 六、 修正後優勢總結

1. **零打擾、純沉浸**：不會在聊天群組刷出突兀的遊戲化「+1 分」提示，保持真正的擬真朋友聊天體驗。
2. **安全防刷可控**：`daily_gain_limit` 可在 `config.yaml` 靈活調整，群友無法靠瘋狂刷字破壞人設。
3. **有據可查**：使用者好奇時隨時輸入 `/kurisu-profile` 即可查看紅莉栖對自己的專屬好感進展。
