串聯discord Rythm 機器人

將以下指令寫成 tool ，llm需要時可以使用。
並建立強制其觸發點歌的指令功能，依照特定要求點歌。
/play (p) - Plays a track (supports search or links)
/playskip (ps, pskip, playnow, pn) - Skips the current song and plays the song you requested
/playtop (pt, ptop) - Adds a song with the given name/url on the top of the queue
/pause - Pauses the current song
/resume - Resumes the current song
/join (summon, start) - Joins the voice channel you are in
/disconnect (dc, leave, fuckoff, stop) - Disconnects from voice channel
/search - Search for tracks
/like (heart, love, grab) - Like/unlike the current track (toggles)
/liked (likes, favorites, favourites) - View your liked tracks
/history (hist, recent) - View your or the server's listening history

/queue (q) - View the current music queue
/move (m) - Move song in queue
/remove (rm) - Remove song from queue
/clear - Clears the music queue
/skipto (st) - Skips to a certain position in the queue
/shuffle - Shuffles the current music queue
/removedupes (rmd, rd, drm) - Removes duplicate songs from the queue
/leavecleanup (lc) - Removes absent user's songs from the queue

/control (ct, c) - Open music controls panel
/nowplaying (np) - Shows information about the currently playing track
/voteskip (skip, s, vs, next) - Vote to skip the current track (requires 50% of users in VC to vote)
/forceskip (fs, fskip) - Force skips current track
/seek - Seek to a position in the current track
/rewind (rwd) - Rewinds by a certain amount of time in the current track
/forward (fwd) - Forwards by a certain amount of time in the current track
/replay - Resets the progress of the current song
/loop (repeat) - Loop the current song
/queueloop (qloop, loopqueue, loopq) - Loop the entire queue
/volume (vol) - Adjust volume

/settings (setting) - Change Rythm's settings
/ping - Checks the bot's response time to Discord
/help - Shows this message
/start - Get started with Rythm
/lyrics (ly) - Show lyrics for the currently playing track (Premium)
/new (changelog) - See what's new in Rythm
/info - Learn about Rythm Bot
/serverprofile - Customize the bot name and avatar for this server (Premium)
/premium - Shows information about Rythm Premium
/effects - Control audio effects for enhanced music experience
/feedback - Share feedback about Rythm
